# Biblioteca Programacao Estruturada

Projeto em C com um pequeno gerenciador de livros em memória e persistência simples.

Como foi organizado (commits marcados nos arquivos fonte):
- Commit 1: Scaffold (estruturas e arquivos).
- Commit 2: Esqueleto do programa e CLI.
- Commit 3: Estruturas de dados (`Book`) e armazenamento em memória.
- Commit 4: Persistência (save/load).
- Commit 5: Documentação e limpeza.

Compilar:

```sh
make
```

Executar:

```sh
make run
```

Testes (simples):

```sh
make test
```
